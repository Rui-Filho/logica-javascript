# 🧠 Lógica de Programação com JavaScript

Repositório criado para registrar minha trajetória de estudos em **lógica de programação utilizando JavaScript**.

O conteúdo é organizado em aulas e exercícios práticos, acompanhando minha evolução desde os conceitos fundamentais até estruturas e problemas mais elaborados.

---

## 📚 Sobre o estudo

Este repositório reúne exercícios, exemplos e desafios desenvolvidos durante meus estudos de lógica de programação.

A proposta é aprender os conceitos por meio da prática, construindo soluções progressivamente mais complexas e desenvolvendo o raciocínio necessário para programar.
